# 列車人狼 — プレイヤーガイド

> 疾走する列車、殺意が潜む旅。あなたは生きて駅に着けるか？

---

## 一、これはどんなゲーム？

列車人狼は**多人数推理対戦ゲーム**です。あなたと友達は同じ列車に乗り込みますが、その中に**殺人者**が紛れ込んでいます。殺人者の目的は気づかれずに全員を始末すること、乗客は生き延びて殺人者を見つけ出すことです。

- **人数**：5～15人
- **所要時間**：デフォルトで約10分（管理者が設定、範囲は5～20分）
- **役職**：殺人者1人、警官1人、残りは全員乗客

---

## 二、1試合の流れ

### ① 乗車し、出発を待つ
列車に乗り込み、車内に立ちます。人数が揃うと列車は**自動で出発**します；管理者が手動で出発を指示することもできます。出発前はアクションバーに「乗車済み人数 / 総人数」が表示されます。出発時にすでに車内にいたプレイヤーは**アドベンチャーモード**で本試合に参加します；乗り遅れたプレイヤーは**スペクテイターモード**に移り、本試合を観戦するだけになります。

> 待機中は2つのアイテムが渡されます：**ガイドブック**（クリックでいつでもゲームプレイとマップ情報を確認）と **先頭車両へテレポート**（クリックで先頭車両に戻る）。出発後、テレポート用アイテムは回収され、ガイドブックだけが残ります。

### ② 役職のランダム配分
出発後、システムが各プレイヤーに役職をランダムに割り当て、あなたが何なのかを個人チャットで通知します。

### ③ タスクをこなし、ゴールドを稼ぐ
ゲーム開始から少し経つと、システムが**ランダムにタスクを配布します**（全員が同時に持つわけではありません）。タスクにはカウントダウンがあり、**時間切れで未完了だとその場で死亡します**（殺人者を除く）。

### ④ 殺人者は暗躍する
殺人者には専用ショップがあり、毒薬、ダガー、手榴弾などの武器を購入できます。殺人者にもタスクは届きますが、それは**偽装**にすぎず、時間切れでも死にません。

### ⑤ 勝敗が決まり、ホームに戻って再開
精算後、全員がホームにテレポートされ、インベントリが空になって開始時アイテムが再配布され、次の試合の準備をします。

### 試合内HUDの説明
試合に入ると、バニラの体力バー、空腹バー、ステータス効果アイコンが**非表示**になります（誰が負傷し、誰が毒状態かを一目で見破られないようにするため）；**経験値バー**も乗客と警官には非表示で、殺人者だけに残ります。すべての重要情報は以下の方法で表示されます：

- **右側の常駐情報パネル**：あなたの名前、役職、ゴールド；殺人者には残りゲーム時間も追加表示
- **左上のタスクパネル**：タスクのヒント + 残り時間のプログレスバー（カウントダウンは経験値バーには表示されなくなりました）
- **アクションバー（インベントリ上部の文字列）**：スタミナバー（スタミナが満タンでないときのみ表示）など
- **チャット欄**：各種メッセージとヒント

## 三、3つの役職、3つの遊び方

| 役職 | 人数 | あなたの目標 |
|------|:--:|------|
| 🩸 殺人者 | 1 人 | 全員を始末し、身分を隠す |
| 🔫 警官 | 1 人 | 乗客を守り、殺人者を見つけ出して殺す |
| 🧑 乗客 | 残り全員 | 生き延び、警官が殺人者を見つけるのを助ける |

### 🩸 殺人者 — あなたは狩人

あなたは列車の中で、自分が何をしているのかを唯一分かっている人間です。

**あなたの強み：**
- 開始時に **100 ゴールド**、その後10秒ごとに自動で **+5 ゴールド**（デフォルト値）
- 専用ショップ（ホットバーの9番スロットを使用）、他人には買えない武器を購入できる
- 右側の情報パネルで**ゲームの残り時間**を確認できる
- **乗客が1人死亡するごとに**：あなたは **+100 ゴールド**、全体の時間が **+60 秒**

**あなたの武器庫（詳細はアイテム早見表）：** ダガー、デリンジャー、バール、ピッキングツール、毒薬、手榴弾、バット、電源切断装置。

---

### 🔫 警官 — あなたは守護者

あなたは列車で唯一の治安維持者で、リボルバーを1丁持っていますが、**誤射に注意**が必要です。

**あなたの強み：** 開始時に**リボルバー**を1丁所持しています。

**あなたの責任：** 乗客を守り、殺人者を見つけ出す；タスクを完了してゴールドを稼ぎ、自分の身を守るアイテムを買う。

**致命的なルール — 誤射ペナルティ：**
あなたの弾丸が**乗客**に命中すると、あなたのピストルは**即座にドロップ**し（地面に落ち、他人が拾うことができます）、さらにあなたは**永久に銃を所持する資格を失います**。発砲前に必ずターゲットを確認してください！

---

### 🧑 乗客 — あなたは生存者

あなたは列車の普通の乗客で、武器も特権もありませんが、あなたは**最も人数の多い集団**です——殺人者もあなたたちの中に紛れ込んでいます。

**あなたの日常：**
- タスクを完了してゴールドを稼ぐ
- ゴールドでアイテムを買って身を守る
- 周囲の人を観察し、警官に協力して殺人者を炙り出す

---

## 四、タスクガイド

タスクはゲーム開始後にランダムで配布され、カウントダウンと進捗は**左上のタスクパネル**に表示されます。もうすぐ時間切れになると、さまざまなマイナス効果が付与されます——これはシステムからの警告です：**早くタスクをやれ！**

> 乗客と警官のタスクが時間切れ = 即死。殺人者が受け取るタスクは偽装にすぎず、時間切れでも死にません。

| # | タスク | やり方 | 豆知識 |
|:--:|------|------|------|
| 1 | **換気** | 先頭車両か最後尾の換気エリアに行ってしばらく立つ | — |
| 2 | **トイレ** | トイレを見つけてしゃがむ | **ミネラルウォーターの瓶**があればそれで即完了 |
| 3 | **睡眠** | 部屋を開け、ベッドを見つけて横になる | 部屋のドアには対応する鍵が必要 |
| 4 | **食事** | 有効な食べ物を何でも食べる | フードトレイから直接取って食べられる |
| 5 | **水分** | 有効な飲み物を何でも飲む | — |
| 6 | **交流** | 他の乗客に近づいてしばらく立つ | **タバコ**があれば1本吸って即完了 |

## 五、スタミナと行動

試合内では**スタミナシステム**が有効になります（管理者がオンオフ可能）：

- スタミナの上限は **100**、満タンでないときだけアクションバーにスタミナバーが表示される
- **ダッシュ**は継続的にスタミナを消費する
- ダッシュをやめて約3秒後、ゆっくりと回復し始める
- スタミナを使い切ると「**疲労困憊**」状態になる：しばらくの間**ダッシュできなくなり**、スタミナがある程度まで戻ると解除される

**ジャンプ**も管理者によって無効にされる場合があります（試合内でのみ有効）。

> スタミナの数値（消費/回復速度）、有効にするかどうか、殺人者が無限スタミナを持つかどうかは、すべて管理者が設定パネルで調整します。

## 六、アイテム早見表

| アイテム | 効果 |
|------|------|
| ダガー | チャージして離すと、前方のプレイヤーを刺殺する |
| リボルバー | 警官の支給銃、発砲可能；乗客に誤射すると銃を落とし永久に失う |
| デリンジャー | 小型の銃、**命中しないと消える** |
| バット | 殺人者がバットを持っている（手持ちでなくてもよい）と約 **30 秒の狂乱**状態に入る（大幅加速、全サーバー告知）、振って命中させれば即死；狂乱終了時に1本消費される |
| 手榴弾 | 投げると、半径 **3 ブロック**内のプレイヤーが即死（**投げた本人も含む**） |
| 毒薬 | **フードトレイ**に毒を盛る；他人が毒入りの食べ物を持ち去って食べると約 **5 秒で吐き気が始まり、50 秒後に毒が回って死亡**（ロイヤルゼリーで解毒可能） |
| 電源切断装置 | 殺人者のみ使用可：すべてのプレイヤーが**20 秒間失明**、殺人者自身は**20 秒間透明**になる |
| バール | ドアをこじ開けてロックする（「ドアと鍵」を参照）、1回使うと1個消費 |
| ピッキングツール | 部屋のドアと列車のドアを開けられる（客車のドアは素手で開く）、**永久に消費されない** |
| 鍵 1～8 | 対応する番号の部屋のドアを開ける、開始時にランダムで配布 |
| 魔法の巻貝 | 他のプレイヤーを右クリックすると、**個人チャット**で相手の役職（殺人者/警官/乗客）が分かる、1個消費 |
| 父の懐中時計 | **長押しで使用**している間アクションバーに残り時間を表示；致命的な攻撃を受けたとき**自動で消費して1回だけ死を回避** |
| 野生のロイヤルゼリー | 飲むと**毒状態を解除** |
| ミネラルウォーター | 飲むとインベントリに**ミネラルウォーターの瓶**が1つ残る |
| ミネラルウォーターの瓶 | トイレタスクで使うと即完了 |
| タバコ | 交流タスクで1本吸うと即完了 |
| カクテル ×5 | オールドファッション / モヒート / マティーニ / コスモポリタン / シャンパン、すべて有効な飲み物 |
| メモ | 何もない場所に使うと内容を編集、他人に使うと送信；死亡後も内容は死体に残る |
| 爆竹 | 右クリックで投げ、重力に従って飛び、ブロックに当たると止まる；着地後に煙が出始め、着地15秒後に爆発して爆竹音を発する（非常に遠くまで聞こえる）、**ダメージは一切ない** |
| ガイドブック | いつでもゲームプレイとマップ情報を確認 |

## 七、ドア、鍵、バール

列車には全部で **3種類のドア**があり、それぞれルールが異なります：

| ドア | 開く条件 |
|:--:|------|
| **部屋のドア** | **対応する番号の鍵**、または**ピッキングツール**が必要 |
| **列車のドア** | **ピッキングツールのみ** |
| **客車のドア** | **アイテム不要**、誰でも開け閉めできる |

**共通ルール：**
- 開いたドアは **3 秒**で自動的に閉まる（バールでロックしたドアを除く）
- ドアのそばの**ボタンが押されると**、対応するドアが自動で開く
- 開始時に各プレイヤーがランダムで鍵を1本受け取り、鍵はインベントリに固定され、**ドロップせず、移動もできない**；あなたが死んでも他人は手に入れられない

**バールの使い方（1個消費）：**
- **部屋のドア、列車のドア**に対して：**立ったまま**（スニークせずに）使用 → ドアを開けて**永久にロック**する（本試合内でロックされ、精算後にリセット）。以後、誰も鍵で開けられない。
- **客車のドア**に対して：**スニーク**して使用 → ドアを閉めて**40 秒間ロック**する。
- ロックされたドアは、鍵を使うと「バールで詰まっている」と表示される。

> ヒント：部屋のドアや列車のドアをこじ開けるのは「一度きりの破壊」で、殺人者がルートを封鎖するのに向いています；客車のドアのロックは40秒しか持たないので、一時的な足止めに向いています。

## 八、ゴールドとショップ

### ゴールドはどうやって増える？
- **殺人者**：開始時100、10秒ごとに+5（デフォルト値）、乗客が1人死亡するごとにさらに+100
- **乗客 / 警官**：タスクを1つ完了するごとに+25（初期値は0）

### どこで買う？

**殺人者ショップ**
- 殺人者がホットバー9番スロットの「殺人者ショップ」アイテムを開く
- 中には殺人者専用の武器とアイテムがある

**自動販売機**
- マップ上の**自動販売機ブロック**を右クリック
- 誰でも買え、商品は管理者が設定する

---

## 九、メモシステム（開始時から使える連絡手段）

全員が開始時にメモを1枚持っており、インベントリに固定されています。

**使い方は？**
- **何もない場所を右クリック** → 編集画面が開き、伝えたいことを入力
- **他のプレイヤーを右クリック** → メモの内容を相手に送信
- もしあなたが死んだら、メモの内容は**あなたの死体に残り**、他人が確認できる

メモはゲーム内で**開始時から使える、追加設定が一切不要な連絡手段**で、情報を伝えたり、助けを求めたり、注意を促したりするのに使います。ホストが追加でオプションのボイスチャットを導入している場合は、直接話すこともできます——ルールは第十二節を参照。

---

## 十、死亡と精算

- **死亡**：あなたのキャラクターは地面に倒れて**死体**になり（あなたの名前付き）、その後**スペクテイターモード**に移り、観戦はできますが行動はできなくなります。
- **転落**：列車の下に落ちた場合も同様に脱落します（ただし死体は残りません）。
- **死体**：他のプレイヤーはあなたの死体を確認できます（そしてメモの内容も）。
- **精算**：一方が勝利すると、全員がホームにテレポートされ、インベントリと状態が空になり、開始時アイテムが再配布され、次の試合の準備をします。

**勝利条件：**

- 殺人者が死亡 → **乗客（乗客 + 警官）の勝利**
- 乗客が全員死亡 → **殺人者の勝利**
- 時間切れ時に乗客が生存 → **乗客の勝利**

## 十一、汎用テクニック早見表

### 殺人者をプレイする
- タスクをするふりをして、みんなと一緒に行動するのが最高の偽装
- 毒薬が最も安全で、正面衝突が不要
- 電源切断後が最高の襲撃タイミングだが、他人の目の前で使ってはいけない
- 身を守るために懐中時計を買う——あなたが死ぬとゲームは終わってしまう

### 警官をプレイする
- 焦って発砲せず、身分を確認してから動く
- まず巻貝で容疑者を検証し、殺人者だと確認してから撃つ
- 懐中時計はあなたの第二の命、必ず買うこと
- 乗客とよくコミュニケーションを取り、情報を集める

### 乗客をプレイする
- 懐中時計が最も重要なアイテム、まずそれを買う
- はぐれず、集団で行動したほうが安全
- 誰の行動がおかしいか注意深く観察する
- メモはあなたの口、それで情報を伝える

## 十二、オプションのボイスチャット（VoiceCraft）

**デフォルトではボイスはありません。これはホストが追加で導入するオプション機能で、使わなくてもゲームにはまったく影響しません。**

使いたい場合、話したいプレイヤーは各自のPC/スマホに **VoiceCraft クライアント**を追加でインストールし、一度バインドを完了する必要があります（VoiceCraft のバインドコマンド `/voicecraft:vcbind <バインドコード>` を実行、バインドコードはサーバー側の画面に表示されます；多くのチュートリアルでは `/vcbind` と略記されています）。バインドは一度だけで済みます：その後ワールドに入り直しても、VoiceCraft クライアントを再起動しても、自動でバインドが復元されます（クライアント再起動後はクライアント自身の識別子によってあなたを認識します）。例外：管理者が音声の「バインド解除」コマンド（`/lw_p1:voice_forget`；**対象を書かないとすべてのバインド記録が消去され、オフラインプレイヤーも含まれます**、自分だけを消したい場合は `@s` と書く）を実行した後は、この記録が消去され、もう一度バインドする必要があります；このコマンドはその時点で進行中の音声には**影響しません**。

有効化後のルール：

| 場面 | 聞こえるかどうか |
|---|---|
| 生存しているプレイヤー ↔ 生存しているプレイヤー | 聞こえる、ただし**32 ブロック以内のみ**（ホストが「音声設定」で変更可能、範囲は4～128ブロック） |
| 観戦（死亡済み）プレイヤー ↔ 観戦プレイヤー | 聞こえる、**距離制限なし、次元をまたいでも聞こえる** |
| 生存者 ↔ 観戦者 | **双方向でまったく聞こえない**（死者は生存者に位置を通報できず、生存者も死者の声を聞けない） |

つまり音声で**列車全体を隔てて**生存者と会話することはできませんが、脱落した者たちが集まって反省会をすることはできます——そして彼らが何を言っても、まだ生きているプレイヤーには一言も聞こえません。

## 十三、よくある質問

**Q：なぜインベントリの物を捨てられないのですか？**
鍵、ガイドブック、メモなどの開始時アイテムは固定されており、誤操作を防ぐために捨てたりインベントリから出したりできません。

**Q：なぜ自分の体力バーと空腹バーが見えないのですか？**
試合内ではこれらの情報が非表示になり、負傷/毒状態の露出を防ぎます。重要な情報はアクションバーとチャット欄を確認してください。

**Q：バットはなぜ突然消えたのですか？**
バットは約30秒間の狂乱を維持するだけで、時間が過ぎると自動的に消えます。

**Q：落とした銃は拾い戻せますか？**
拾い戻せますが、警官が一度でも乗客に誤射すると**永久に発砲資格を失う**ため、拾い戻しても意味がありません。

**Q：タスクに失敗するとどうなりますか？**
乗客と警官はその場で死亡します；殺人者のタスクは偽装にすぎず、時間切れでも何も起こりません。
